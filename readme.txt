=== Mercury Electrical QLD ===
Custom one-page theme by OnSite Websites.

== Setup ==
1. Deploy the theme from GitHub (Hostinger auto-deploy to wp-content/themes/mercury-electrical)
   and activate it. On activation it imports the photos into the Media Library, builds the
   Home and Privacy Policy pages from editable blocks, sets Home as the front page and sets
   the site icon. (If that ever needs re-running, a notice in the dashboard offers it.)
2. Business details (phone, email, hours, ABN, licences, service area, meta title and
   description, Google Maps embed, Google Business Profile link, reviews shortcode, Fluent
   Forms form ID): Appearance → Customize → Business Details.
3. Page content: Pages → Home, edited in the standard block editor.
4. Quote form: create a Fluent Forms form titled "Quote Request" (or enter its ID in Business
   Details) and it replaces the stand-in form automatically.
5. Reviews: paste the Trustindex shortcode into Business Details → Reviews shortcode.

== How code deploys ==
Theme files live in GitHub (OnSite-Websites/mercury-electrical-theme, branch main). Every push
to main deploys to the live site. Never edit theme files on the server.
